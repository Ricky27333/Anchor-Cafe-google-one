## 🚀 How to Deploy to Render (Static Site)

### Method 1: Automatic Blueprint (Recommended)
1. Push your repository to GitHub or GitLab.
2. In your [Render Dashboard](https://dashboard.render.com/):
   - Click **New +** → **Blueprint**.
   - Connect your repository.
   - Render will automatically read `render.yaml` and configure the static site.
   - Click **Apply**.

### Method 2: Manual Static Site Setup
1. In the [Render Dashboard](https://dashboard.render.com/):
   - Click **New +** → **Static Site**.
   - Connect your GitHub / GitLab repository.
2. Fill in the fields:
   - **Name**: `anchor-cafe` (or your preferred name)
   - **Branch**: `main`
   - **Root Directory**: leave blank (or `./`)
   - **Build Command**: leave blank (pure HTML/CSS/JS, no build step required)
   - **Publish Directory**: `.` (or `./`)
3. Click **Create Static Site**.
4. Your website will be live in seconds with free SSL / HTTPS (e.g., `https://anchor-cafe.onrender.com`).
